## 运行模式

| 模式 | 需要 Root | 适用情况 |
| --- | --- | --- |
| VPN | 否 | 默认选择。Android 通过 VpnService 接管流量，需要系统 VPN 授权。 |
| Root TUN | 是 | 由 Root 守护进程和 mihomo 创建 TUN 设备。 |
| 透明代理 | 是 | 由 Root 守护进程配置 TPROXY/重定向规则。 |

Root 模式需要设备已正确提供 `su`。启动后检查通知栏常驻通知；系统若限制通知权限或后台运行，先在系统设置中允许通知并取消电池限制。

## 节点、Provider 与规则

节点页读取正在运行的 mihomo 数据，不是订阅文件的静态预览。因此代理未启动或已经停止时，导航栏不会显示节点页。启动后可以选择策略组节点、测试延迟和查看 Provider。

导入或更新订阅时，YumeBox 会预取 HTTP 规则集和代理 Provider。每个 Provider 单独处理：下载失败不会导致订阅导入失败，mihomo 会在运行时补下载缺失文件。

## 覆写开关

网络设置中的“禁用所有覆写”只在 Root TUN 和透明代理模式下生效。启用后，YumeBox 不应用用户覆写、内置模式补丁、可视化运行设置或 Provider 路径改写，直接按你的配置运行。

这适合已经完整维护 mihomo 配置的人。VPN 模式仍由 Android 的 VpnService 管理，不能使用这个旁路。

## 常用设置

| 设置 | 建议 |
| --- | --- |
| 启动时更新配置 | 使用订阅时保持开启。 |
| 自定义 User-Agent | 机场要求特定客户端标识时填写；留空使用默认值。 |
| 显示流量通知 | 保持开启，便于确认服务仍在运行。 |
| 电池优化无限制 | 建议为 YumeBox 设置为无限制，降低后台被杀概率。 |
| DNS 劫持 | VPN 模式下通常保持开启；有自定义 DNS 需求时再调整。 |

## 深度链接

| 链接 | 打开位置 |
| --- | --- |
| `yumebox://page/home` | 首页 |
| `yumebox://page/proxy` | 运行中的节点页 |
| `yumebox://page/profiles` | 配置 |
| `yumebox://page/settings` | 设置 |
| `yumebox://screen/network` | 网络设置 |
| `yumebox://screen/override` | 覆写 |
| `yumebox://screen/log` | 日志 |

<Note>未识别的链接会被忽略，不会中断当前页面。</Note>
