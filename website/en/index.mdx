## Introduction

[YumeBox](https://github.com/YumeYucca/YumeBox) is a branch management tool derived from the visual novel [9-nine- ARTEISIA](https://9-nine-project.com/game/asnine), with additional features for ease of use.

Before using YumeBox, please be aware of the following:

- This project is an extension of 9-nine- ARTEISIA. To play the visual novel, visit [9-nine-project](https://9-nine-project.com/game/asnine).
- The application icon and brand identity of [YumeBox](https://github.com/YumeYucca/YumeBox) are copyrighted by the project owner.
- Forks must not use the [YumeBox](https://github.com/YumeYucca/YumeBox) `project name` or retain the `original icon`.
- First-party content in forks must not contain anything associated with the [Overflowing Memories Working Group](https://oom-wg.dev/), including domains such as `*.oom-wg.dev` and `*.gal.tf`, channels, or group chats.

No fork may use this content except to reasonably identify [YumeBox](https://github.com/YumeYucca/YumeBox) as the source project.

## Special note

**~~The author knows nothing about the code in this project. The code is either working or not working; there is no third state.~~**

**YumeBox follows one core principle: overwrite as little of the original configuration as possible. It does not apply unnecessary overrides and refuses to abstract explicit configuration [fields](https://wiki.metacubex.one/config/) into ambiguous or vaguely worded feature switches.**

## Development

YumeBox has gradually stabilized through continued iteration. It will remain **open source and free**, with a commitment to never collect or upload private data and never include advertising.

### **June 1, 2026**

***To support the project's continued development, some signature verification has been removed and several terms have been added. These terms only restrict releases of forked versions. Do not create confusion, ambiguity, or unnecessary burden for this project.***
