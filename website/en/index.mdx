## Introduction

[FlyCat](https://github.com/LM-Firefly/FlyCat) is an open-source Android client based on [YumeBox](https://github.com/YumeYucca/YumeBox), using [mihomo](https://github.com/MetaCubeX/mihomo) as its core, providing proxy management and configuration override features.

FlyCat inherits YumeBox's core principle: overwrite as little of the original configuration as possible. It does not apply unnecessary overrides and refuses to abstract explicit configuration [fields](https://wiki.metacubex.one/config/) into ambiguous feature switches.

## Development

FlyCat is built on YumeBox and continues to iterate. It will remain **open source and free**, with a commitment to never collect or upload private data and never include advertising.
