<Update label="2026-7-7" tags={["Features", "Improvements", "Fixes"]} description="v0.5.3">
  ## Changes

  - Added application data export and restore, with an entry in Settings.
  - Added a remote mihomo controller with a quick dialog.
  - Added an access-control panel shortcut under `Labs -> Panel` (requires the relevant app permission).
  - Added network URL import for override configurations.
  - Updated intelligent regional-app detection in access control.
  - Applied `include/exclude-package` to the VPN builder.
  - Added Age key-pair generation.
  - Reworked first-run guidance, added Home previews and skeleton animations, and removed obsolete pages.
  - Added a consistent empty state for proxy, Provider, and override lists.
  - Automated builds now inject a unique version number.
  - Improved the battery-optimization settings shortcut and status refresh.
  - Improved access-control layout, actions, and sorting.
  - Smoothed proxy-sheet and editor animations; wallpaper preview now uses long press.
  - Tightened settings summaries and switched YAML highlighting to a compact tmLanguage.
  - Redesigned the Moe Home control and About-page header card.
  - Removed redundant copy and refined component use, dialog behavior, and navigation borders.
  - **Completely fixed proxy selection persistence and synchronization.**
  - Fixed YAML `<<` merge expansion and inherited fields missing from proxy groups and rule providers.
  - Fixed background coroutine scope, `SessionRuntime` snapshot synchronization, raw-restore cache refresh, and Age decryption.
  - Fixed image links, missing translations (#125), and search-overlay transitions.
  - Removed the proxy-page network-panel shortcut, navigation-style selector, test-all-proxies action, screenshot biometric option, and obsolete onboarding.

  **Full Changelog**: [v0.5.2...v0.5.3](https://github.com/YumeYucca/YumeBox/compare/v0.5.2...v0.5.3)

  [Download](https://github.com/YumeYucca/YumeBox/releases/tag/v0.5.3)
</Update>

<Update label="2026-3-29" tags={["Features", "Improvements", "Fixes"]} description="v0.5.0">
  ## Changes

  - **Added a new override system with multiple configurations, presets, visual editing, routing templates, and quick add/edit actions.**
  - **Custom overrides support the `start`, `end`, `merge`, and `force` suffix operations.** See [override documentation](/override/override).
  - **Added Root TUN support; it requires Root but not Android VPN.**
  - Improved onboarding, Toast dialogs, interaction details, and navigation feedback.
  - Added configuration-link editing, a Connections page, Rust override parsing and runtime configuration generation, editor syntax checks and partial completion, single-proxy latency tests, profile preview, proxy-page test/sort animations, extra proxy tags, link preview, GeoX downloads, and a redesigned Log page.
  - Reworked parts of the bridge and updated iconography and the default theme to dark green.
  - Fixed dialogs that could not close, proxy-page padding, traffic-routing mode, unavailable traffic statistics, device-specific icon issues, and imports that could hang.
  - Improved dark-theme color extraction, proxy-group icon sizing, dialog performance, page/card spacing, top-bar blur, page transitions, Home swiping, persisted proxy selection, Home Unknown/proxy padding, and navigation hiding.
  - Removed proxy-page dialog routing setup.
