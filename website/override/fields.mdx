## 文件类型

| 后缀 | 行为 |
| --- | --- |
| `.yaml` / `.yml` | 解析为补丁并合并到当前配置。 |
| `.js` | 执行 `main(profile)`，返回值作为下一版配置。 |

空文件会跳过并记录 warning。未知扩展名会使配置编译失败。

## YAML 字段修饰符

| 写法 | 行为 |
| --- | --- |
| `key: value` | 标量覆盖；对象递归合并；普通列表替换。 |
| `key-start: [...]` | 在原列表开头插入项目。 |
| `key-end: [...]` | 在原列表末尾追加项目。 |
| `key-merge: {...}` | 递归合并 Map，不移除已有键。 |
| `key-force: value` | 完整替换字段，不做合并。 |
| `<key-end>: value` | 把带修饰符的字段名当作普通字段名。 |

`rules`、`proxies` 和 `proxy-groups` 等已知列表支持 `-start`、`-end`。同名代理或策略组在合并后保留最后出现的定义。

```yaml
rules-start:
  - DOMAIN-SUFFIX,lan,DIRECT

rules-end:
  - DOMAIN-SUFFIX,example.com,PROXY

hosts-merge:
  router.local: 192.168.1.1

dns-force:
  enable: true
  nameserver:
    - https://dns.alidns.com/dns-query
```

## JavaScript

`main(profile)` 可以直接修改并返回 `profile`，也可以返回新的对象。返回 `undefined`、数组或标量会使当前脚本失败，并保留执行前配置。

```js
async function main(profile) {
  const response = await fetch("http://127.0.0.1:8080/rules.yaml");
  if (!response.ok) return profile;

  const remote = await response.yaml();
  return deepMerge(profile, remote, true);
}
```

### `deepMerge`

| JS 写法 | 行为 |
| --- | --- |
| `key: value` | 覆盖标量或列表；对象递归合并。 |
| `"+key": [...]` | 在列表开头插入项目。 |
| `"key+": [...]` | 在列表末尾追加项目。 |
| `"key!": {...}` | 用对象完整替换目标字段。 |
| `"<key>": value` | 使用字面字段名，避免修饰符被识别。 |

### 可用 API

| API | 用途 |
| --- | --- |
| `yaml.parse(text)` / `yaml.stringify(value)` | YAML 与对象互转。 |
| `deepMerge(target, patch, true)` | 使用 JS 覆写规则合并对象。 |
| `fetch(url, init?)` | 发起 HTTP 请求。 |
| `response.text()` / `json()` / `yaml()` | 读取响应体。 |
| `console.log/info/warn/error/debug` | 写入同名 `.log` 文件。 |
| `Buffer.from()`、`b64e()`、`b64d()` | UTF-8/Base64 转换。 |

<Warning>内置 `fetch` 只支持 `http://`，不支持 HTTPS。网络导入覆写文件本身可以使用 HTTP 或 HTTPS。</Warning>

## 失败行为

| 情况 | 结果 |
| --- | --- |
| YAML 解析失败 | 本次配置编译失败。 |
| JS 运行或返回值失败 | 跳过当前 JS 覆写，保留执行前配置并记录 warning。 |
| age 加密配置 | 覆写 warning 和 JS 日志会隐藏配置内容。 |

YumeBox 随后还会应用运行时约束，例如 provider 私有路径、DNS 默认值与当前运行模式所需的补丁。Root 模式启用“禁用所有覆写”时，这些运行时补丁也会跳过。
