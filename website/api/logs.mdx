## 获取实时日志

<RequestExample>
```bash GET /logs
curl http://127.0.0.1:9093/logs
```
</RequestExample>

`GET /logs`

建立 SSE 连接，返回实时日志流，每条一行 JSON。

### 查询参数

<ParamField query="level" type="string">
  日志级别过滤。可选值：`info`、`warning`、`error`、`debug`。
</ParamField>

<ParamField query="format" type="string">
  传入 `structured` 获取结构化日志（`time`/`level`/`message`/`fields`）。
</ParamField>

### 响应

<ResponseField name="200" type="object">
  流式日志，每条一行 JSON。

  兼容模式（默认）：

  | 字段 | 类型 | 说明 |
  | --- | --- | --- |
  | `type` | string | 日志级别 |
  | `payload` | string | 日志内容 |

  Structured 模式（`format=structured`）：

  | 字段 | 类型 | 说明 |
  | --- | --- | --- |
  | `time` | string | 时间戳 |
  | `level` | string | 日志级别 |
  | `message` | string | 日志消息 |
  | `fields` | array | 附加字段 `[{key, value}]` |
</ResponseField>
